Panduan Rekap Absensi LUNAPOS

1. Sesuaikan Master Jadwal Shift

Atur jam masuk resmi outlet Anda untuk hari Weekday (Senin–Jumat) dan Weekend (Sabtu–Minggu)[cite: 1].

2. Atur Toleransi Keterlambatan (Opsional)

Tentukan batas toleransi keterlambatan (dalam menit)[cite: 1].

3. Unggah File Excel Absensi LUNAPOS

Pilih atau tarik file Excel laporan absensi LUNAPOS (.xlsx / .csv)[cite: 1].

4. Lihat Ringkasan & Filter Outlet

Sistem otomatis mengagregasi total kehadiran, total jam kerja, frekuensi keterlambatan, dan total menit telat[cite: 1].

5. Klik Nama Karyawan untuk Log Detail

Klik pada nama karyawan yang bergaris bawah biru untuk membuka pop-up log rincian tanggal, hari, dan menit keterlambatan[cite: 1].

6. Ekspor Hasil Laporan

Gunakan tombol Unduh Excel atau Unduh PDF[cite: 1].
