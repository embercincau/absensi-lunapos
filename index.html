📖 Panduan Rekap Absensi LUNAPOS

1. Sesuaikan Master Jadwal Shift

Atur jam masuk resmi outlet Anda untuk hari Weekday (Senin–Jumat) dan Weekend (Sabtu–Minggu).

2. Atur Toleransi Keterlambatan (Opsional)

Tentukan batas toleransi keterlambatan (dalam menit).

3. Unggah File Excel Absensi LUNAPOS

Pilih atau tarik file Excel laporan absensi LUNAPOS (.xlsx / .csv).

4. Lihat Ringkasan & Filter Outlet

Sistem otomatis mengagregasi total kehadiran, total jam kerja, frekuensi keterlambatan, dan total menit telat.

5. Klik Nama Karyawan untuk Log Detail

Klik pada nama karyawan yang bergaris bawah biru untuk membuka pop-up log rincian tanggal, hari, dan menit keterlambatan.

6. Ekspor Hasil Laporan

Gunakan tombol 📥 Unduh Excel atau 📄 Unduh PDF.
